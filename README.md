# Django Catalog

Учебный проект на Django для домашней работы по веб-разработке.

## Описание

Проект содержит приложение `catalog` с главной страницей и страницей контактной информации.

## Технологии

- Python 3.14
- Django 6.1
- Bootstrap
- Git / GitHub

## Установка и запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите сервер разработки:

```bash
python manage.py runserver
```

4. Откройте в браузере:

```text
http://127.0.0.1:8000/
```
