# Django Catalog

Учебный проект на Django, созданный в рамках домашней работы по веб-разработке.

## Описание проекта

Проект содержит Django-приложение `catalog` с двумя страницами:

- главная страница;
- страница с контактной информацией.

Страницы свёрстаны с использованием Bootstrap.

## Технологии

- Python 3.14
- Django 6.1.1
- Bootstrap 5
- Git
- GitHub

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Примените миграции:

```bash
python manage.py migrate
```

5. Запустите сервер разработки:

```bash
python manage.py runserver
```

6. Откройте проект в браузере:

```text
http://127.0.0.1:8000/
```
